# 🚀 mac-m1-zero-token

> **Экосистема локальных утилит macOS (Apple Silicon M1/M2/M3/M4) для аппаратной разгрузки LLM (Gemini CLI, Codex, Claude Code) и работы с 0 расходом облачных токенов.**

---

## 🎯 Философия проекта
Современные мультимодальные модели (Gemini 2.5 Pro, Claude 3.5 Sonnet, GPT-4o) берут огромную плату за «тяжелые» входные данные: скриншоты, сканы документов, PDF-файлы на 100 страниц и аудиозаписи. Загрузка нескольких картинок или скана договора способна сжечь **100 000+ токенов** за один запрос и мгновенно забить контекстную память агента «шумом».

**Принцип mac-m1-zero-token:**
1. Ни одного пикселя или аудиобайта не должно отправляться в облачный API.
2. Процессор Apple Silicon (Neural Engine, аппаратные медиа-декодеры, Unified Memory) выполняет всю черновую работу **локально, оффлайн, мгновенно и бесплатно**.
3. В облачную LLM попадает **только концентрированный, чистый текст (Markdown / TXT)**.

## 🛠️ Установка на любой Mac за 1 минуту

Если вы переехали на новый компьютер Mac или обновили систему:

```bash
git clone https://github.com/Santory12/mac-m1-zero-token.git
cd mac-m1-zero-token
chmod +x install.sh
./install.sh
```

Скрипт автоматически:
1. Скомпилирует нативный ARM64-бинарник `ocr` с оптимизацией `-O`.
2. Положит его в `~/.local/bin/ocr`.
3. Добавит путь в `PATH` в `~/.zshrc` (если его там не было).

## ⚡ Модуль 1: Утилита `ocr` (Apple Vision Framework)

Написана на нативном Swift без внешних тяжелых зависимостей. Задействует Apple Neural Engine и многопоточный OCR.

### Сценарии использования:

#### 1. Мгновенный скриншот без сохранения файлов (Killer-feature)
1. Нажмите `Cmd + Ctrl + Shift + 4` (скриншот области сразу в буфер обмена).
2. В терминале наберите:
   ```bash
   ocr
   ```
3. **Текст мгновенно распознан и уже лежит в вашем буфере обмена.** Просто нажмите `Cmd + V` в любом приложении.

#### 2. Распознавание файлов изображений (PNG, JPG, HEIC, WebP)
```bash
ocr /path/to/invoice.png
```
* Распознает русский, английский и европейские языки (французский, немецкий).
* Выводит результат в терминал.
* Создает текстовый файл `/path/to/invoice.txt` рядом.
* Копирует текст в буфер обмена.

#### 3. Извлечение текста из PDF (Текст + Сканы)
```bash
ocr contract.pdf
```
* Если в PDF есть текстовый слой — мгновенно вычитывает его через нативный `PDFKit`.
* Если страницы отсканированы (картинки) — автоматически рендерит их и прогоняет через Apple Vision OCR.

#### 4. Конвертация Word в чистый Markdown
```bash
ocr specifications.docx
```
* Конвертирует документ в компактный `specifications.md` через Pandoc, удаляя разметку стилей Word.

## 📄 Модуль 2: Утилита `cleandoc` (Boilerplate Stripper)

Предназначена для очистки клиентских ТЗ, договоров и RFP от «воды» перед тем, как скармливать их в LLM.

### Что делает `cleandoc`:
1. Автоматически принимает `.docx`, `.pdf`, `.md`, `.txt`.
2. Вырезает разделы с юридической водой: «Предмет соглашения», «Ответственность сторон», «Порядок расчетов», «Форс-мажор», «Конфиденциальность/NDA», «Реквизиты и подписи».
3. Удаляет колонтитулы, номера страниц, служебные плашки («Коммерческая тайна»).
4. Оставляет только **суть: функциональные требования, интеграции, архитектуру, сценарии, роли и WBS**.
5. Сохраняет компактный файл `*_cleaned.md` и подсчитывает процент сэкономленных токенов.

### Использование:
```bash
cleandoc client_tz.docx
# или
cleandoc rfp.pdf
```
*Выведет статистику сэкономленных токенов и создаст `client_tz_cleaned.md`.*

## 🤖 Инструкция для ИИ-агентов (Gemini CLI, Codex, Claude Code)

### Железное правило (Mandate):
Каждый ИИ-агент, работающий в этой системе, обязан соблюдать **Zero-Image-to-Cloud Mandate**:

1. **Запрет мультимодального чтения:** Никогда не вызывать встроенные функции чтения картинок (`read_file` для изображений) или передавать бинарные сканы в облачную модель.
2. **Аппаратный вызов:** При получении пути к файлу `.png`, `.jpg`, `.jpeg`, `.heic`, `.webp` или `.pdf` агент **ОБЯЗАН** первым шагом выполнить bash-команду:
   ```bash
   ocr <путь_к_файлу>
   ```
3. **Чтение текста:** Работать исключительно с созданным текстовым файлом (`.txt` или `.md`).
